## Project Overview
The objective of this project is to **redesign Kotak Bank’s mobile app** to improve usability, visual clarity, and overall user experience.  
The redesign addresses:

- Usability issues and cluttered navigation  
- Inconsistent UI components  
- Accessibility and readability improvements  

**Key Goals:**  
- Simplify navigation with a consistent bottom menu  
- Highlight key banking actions (Send Money, Pay Bills, Transaction History)  
- Modernize UI with a clean, professional look  
- Ensure mobile responsiveness and scrollable content  

---

## Problem Statement
The existing app has multiple pain points for users:  

- Complex navigation and deep menus  
- Visual clutter and inconsistent icons  
- Poor readability and touch targets  

The redesign aims to create a **user-friendly, intuitive, and visually appealing mobile banking experience**.  

---

## Solution
- **Simplified Navigation:** Bottom navigation bar with 5 main items → Home, Send Money, History, Bills, Profile  
- **Modern Color Palette:**  
  - Primary: #FF5733 (Kotak Orange)  
  - Secondary: #FFFFFF  
  - Neutral: #F5F5F5  
- **Typography:** Clear heading hierarchy, legible body text, and spacing rules  
- **Consistent Components:** Buttons, input fields, dropdowns, cards, icons  
- **Mobile-First Design:** Scrollable screens for mobile devices; touch-friendly layout  
- **Core Banking Tasks:** Users can complete any transaction in 3–5 clicks

## Workflow / User Flow
1. **Login → OTP Verification → Home / Dashboard**  
2. **Home → Accounts → Scrollable Account Details → Home**  
3. **Home → Send Money → Payment Confirmation → Payment Success → Home**  
4. **Home → Transaction History → Scrollable History → Home**  
5. **Home → Bill Payment → Scrollable Bills → Home**  
6. **Home → Profile → Settings / Preferences → Home**  
7. **Home → Add Funds / Transfer History → Home**  
8. **Home → Help / Support → Home**  

**Navigation:**  
- Bottom navigation bar is consistent across all screens  
- Users can perform any core banking task within 3–5 clicks
